## О квесте

Жанр: квест / головоломка  
Язык программирования: Python  
Интерфейс: графический, создан с помощью Tkinter  
Формат: одиночная игра

«Побег из дома» — небольшая игра, в которой нужно исследовать
комнаты, найти подсказку, открыть сейф и выбраться из запертого дома.

Игрок управляет персонажем с помощью кнопок. Каждая комната
сопровождается изображением и текстовым описанием.
Найденные предметы отображаются в инвентаре.

Проект начинался как консольная игра, а затем получил графический
интерфейс.

## Сюжет

Главный герой оказывается заперт в доме. Входная дверь закрыта,
а ключ спрятан в сейфе с кодовым замком.

Чтобы выбраться, необходимо исследовать комнаты и найти записку
с паролем.

### Основные задачи

1. Осмотреть доступные комнаты.
2. Найти подсказку о местонахождении пароля.
3. Обыскать кровать в спальне и забрать записку.
4. Ввести код от сейфа в прихожей.
5. Получить ключ.
6. Открыть входную дверь.

### Завершение игры

Победа наступает после открытия входной двери ключом из сейфа.

Игрок также может закрыть игру, не завершив прохождение.
Это выход из программы, а не отдельная сюжетная концовка.

## Особенности

В игре реализованы:

- Перемещение между комнатами с помощью кнопок.
- Изображения комнат.
- Текстовые описания и подсказки.
- Инвентарь на основе списка.
- Добавление записки и ключа в инвентарь.
- Проверка наличия предметов.
- Поле ввода пароля от сейфа.
- Проверка правильности пароля.
- Защита от повторного добавления одинаковых предметов.
- Перезапуск игры после победы.
- Сообщение об ошибке, если изображение не удалось загрузить.

### Технические особенности

- Код разделён на функции.
- Интерфейс создан с помощью Tkinter.
- Размер окна задан как 1920 × 1080 пикселей.
- Для хранения предметов используется список `inventory`.
- Для построения путей к изображениям используется `pathlib`.
- Ошибки загрузки картинок обрабатываются через `try / except`.
- Изображения загружаются из папки `images` рядом с файлом игры.
- Слишком большие изображения уменьшаются целым коэффициентом
  с сохранением пропорций.

### Ограничения текущей версии

- Сохранение и загрузка прогресса не реализованы.
- После закрытия программы прогресс теряется.
- Нет системы здоровья, времени или случайных событий.
- Реализована одна победная концовка.
- Код от сейфа можно ввести без предварительного нахождения записки.
- На экране меньше 1920 × 1080 окно может не помещаться целиком.

## Установка и запуск

### Требования

- Python 3 с доступным Tkinter.
- Файлы проекта.
- Изображения в папке `images`.

В текущей версии используются встроенные модули.
Устанавливать Matplotlib или Pillow не требуется.

### Запуск

1. Скачайте проект или скопируйте его на компьютер.
2. Откройте папку проекта в VS Code.
3. Выберите интерпретатор Python.
4. Откройте терминал в папке проекта.
5. Выполните команду:

```bash
python house_game.py
```

Если основной файл называется иначе, укажите его название.

### Проверка Tkinter

Для проверки графической библиотеки выполните:

```bash
python -m tkinter
```

Должно открыться тестовое окно Tkinter.

### Подготовка изображений

Положите изображения в папку `images`.

Названия файлов должны точно совпадать с названиями в коде:

| Файл | Содержание |
|---|---|
| `corridor.png` | Коридор с дверями |
| `living_room.png` | Гостиная |
| `kitchen.png` | Кухня |
| `bedroom.png` | Спальня с кроватью |
| `hall.png` | Прихожая с выходной дверью |
| `safe.png` | Сейф с кодовым замком |
| `victory.png` | Открытая дверь или улица |

Рекомендуемый размер изображений — 1000 × 450 пикселей.

Для этой версии используются PNG-файлы.
Простое переименование `.jpg` в `.png` не меняет формат изображения:
его нужно сохранить как PNG в графическом редакторе.

Если изображение отсутствует или не загружается, игра показывает
сообщение с путём к нужному файлу и продолжает работать.

## Игровой процесс

### Коридор

Начальная сцена. Игрок может перейти в гостиную, кухню,
спальню или прихожую.

### Гостиная

Здесь находится подсказка:

> «Код спрятан там, где ты спишь».

### Кухня

На кухне можно узнать, что ключ от входной двери хранится в сейфе.

### Спальня

При осмотре кровати игрок находит записку с кодом.
Записка добавляется в инвентарь.

### Прихожая

Здесь расположены сейф и выходная дверь.

Игрок вводит пароль, забирает ключ из сейфа,
а затем использует его для открытия двери.

### Инвентарь

Инвентарь постоянно отображается в нижней части окна.

В нём могут находиться:

- Записка с кодом.
- Ключ.

При повторном осмотре предметы не дублируются.

### Повторное прохождение

После победы доступна кнопка «Играть снова».
Она очищает инвентарь и возвращает игрока в коридор.
